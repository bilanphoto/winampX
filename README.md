# Winamp 2.91 Web Edition (HTML5 / CSS3 / JavaScript)

เว็บแอปพลิเคชันจำลองเครื่องเล่นเพลง **Winamp 2.91** ต้นฉบับแบบ 100% ครบทุกฟังก์ชัน ทำงานบนเบราว์เซอร์ได้ทันทีโดยไม่ต้องติดตั้งโปรแกรมใดๆ เพิ่มเติม

---

### ✨ ฟังก์ชันและความสามารถหลัก

1. **หน้าต่างหลัก (Main Player)**
   - นาฬิกาดิจิทัล 7-Segment สไตล์ Retro สีเขียวเรืองแสง (คลิกสลับดูเวลาที่เล่นไปแล้ว หรือเวลาที่เหลืออยู่ พร้อมเครื่องหมายลบ)
   - **Real-time Spectrum Analyzer & Oscilloscope**: แสดงกราฟสเปกตรัมความถี่ 16 แท่ง พร้อมระบบ Peak Hold ตกอย่างนุ่มนวลแบบ 60 FPS (คลิกที่หน้าจอเพื่อสลับโหมดเป็น Oscilloscope กราฟคลื่นเสียง หรือปิด)
   - แถบไฟวิ่ง (Marquee) แสดงชื่อเพลง ศิลปิน ความยาวเพลง
   - ไฟบอกค่า kbps, kHz และโหมด Stereo / Mono
   - แถบเลื่อนปรับระดับเสียง (Volume Fader) และบาลานซ์ซ้าย-ขวา (Balance Fader พร้อมจุดกึ่งกลาง)
   - แถบเลื่อนข้ามเวลาเพลง (Seek / Scrubber)
   - แผงปุ่มควบคุมหลัก: Previous, Play, Pause, Stop, Next, Eject (เปิดไฟล์เพลง)
   - โหมด **Shuffle** (สุ่มเพลง) และ **Repeat** (วนซ้ำเพลงเดียว / วนทั้งเพลย์ลิสต์)
   - ปุ่มพับหน้าต่าง (Window Shade Mode) จำลอง Winamp ต้นฉบับ

2. **หน้าต่างอีควอไลเซอร์ (Equalizer Window)**
   - กราฟเส้นโค้งจำลองการปรับแต่งย่านความถี่ (Spline Curve Display) แบบเรียลไทม์
   - สวิตช์ **ON** และ **AUTO**
   - แถบปรับ **PREAMP** (-12dB ถึง +12dB)
   - แถบปรับแต่ง 10 ย่านความถี่จริงผ่าน Web Audio API: `60Hz`, `170Hz`, `310Hz`, `600Hz`, `1kHz`, `3kHz`, `6kHz`, `12kHz`, `14kHz`, `16kHz`
   - เมนู **PRESETS** ครบทุกพรีเซ็ตยอดนิยมของ Winamp:
     - *Flat, Rock, Pop, Techno, Classical, Club, Dance, Full Bass, Full Bass & Treble, Full Treble, Laptop Speakers, Live, Party, Reggae, Soft Rock, Vocal*

3. **หน้าต่างเพลย์ลิสต์ (Playlist Window)**
   - นำเข้าไฟล์เสียงได้ทั้ง **MP3, WAV, OGG, FLAC, M4A, AAC** (กดปุ่ม ADD หรือลากไฟล์มาวาง Drag & Drop ลงในหน้าต่างได้โดยตรง)
   - **ระบบปรับขนาดหน้าต่างเพลย์ลิสต์ (Resizable Playlist)**: สามารถคลิกลากที่มุมขวาล่าง (`Resize Grip`) หรือขอบล่างของหน้าต่างเพื่อย่อ-ขยายความสูงได้อิสระ (116px ถึงเต็มความสูงจอ) และดับเบิลคลิกเพื่อสลับขนาดกะทัดรัด/ขยายใหญ่
   - **แถบเลื่อน Scrollbar สมบูรณ์แบบ**: Thumb เลื่อนตามการ Scroll จริง หรือคลิกลาก Thumb เพื่อเลื่อนดูเพลงได้อย่างลื่นไหล
   - ไฮไลท์เพลงที่กำลังเล่นอยู่ พร้อมเอฟเฟกต์เรืองแสงสีเขียว
   - ดับเบิลคลิกเพื่อเล่นเพลงทันที
   - ปุ่ม **ADD**: เพิ่มไฟล์เพลง, เพิ่มทั้งโฟลเดอร์, เพิ่มเพลงตัวอย่าง
   - ปุ่ม **REM**: ลบเพลงที่เลือก, Crop (เก็บเฉพาะเพลงที่เลือก), ล้างทั้งเพลย์ลิสต์
   - ปุ่ม **SEL**: เลือกทั้งหมด, ยกเลิกการเลือก, สลับการเลือก (Invert)
   - ปุ่ม **MISC**: เรียงตามชื่อเพลง, เรียงตามชื่อไฟล์, สุ่มลำดับเพลง (Randomize), กลับลำดับ (Reverse)
   - ปุ่ม **LIST OPTS**: ส่งออกเพลย์ลิสต์เป็นไฟล์ `.m3u`, บันทึกลง IndexedDB
   - แผงควบคุมขนาดเล็ก (Mini Transport) และเวลาเล่นรวมของเพลย์ลิสต์

4. **ระบบจำค่าอัตโนมัติ (Persistence ผ่าน IndexedDB)**
   - บันทึกไฟล์เพลงที่ผู้ใช้นำเข้าลงในฐานข้อมูลเบราว์เซอร์ **IndexedDB** อัตโนมัติ ทำให้เมื่อ Refresh หรือเปิดเบราว์เซอร์ใหม่ เพลงและเพลย์ลิสต์ยังคงอยู่ครบถ้วน
   - จดจำระดับเสียง, บาลานซ์, ค่าอีควอไลเซอร์, ตำแหน่งหน้าต่าง, ความสูงเพลย์ลิสต์, สกินที่เลือก, โหมดวนซ้ำ/สุ่มเพลง

5. **ระบบหน้าต่างแม่เหล็ก (Magnetic Window Snapping)**
   - ลากแต่ละหน้าต่างได้อย่างอิสระ เมื่อลากเข้าใกล้กันในระยะ 14px หน้าต่างจะดูดติดกันเป็นชุดเหมือนโปรแกรม Winamp ต้นฉบับ
   - โหมดพับหน้าต่าง (Window Shade Mode) ดับเบิลคลิกที่ Titlebar เพื่อย่อเหลือเฉพาะแถบบนขนาด 14px

6. **ระบบสกิน 3 รูปแบบ (Skin Switcher & Main Menu)**
   - **Midnight Gold (Violet / Gold)**: สกินสีม่วงเข้มมิดไนท์ตัดเส้นคู่ทองคำ (Gold Pinstripes) ไฟ LED สีเขียวนีออน พร้อมราง EQ สีเหลืองทอง ตรงตามรูปต้นแบบล่าสุด
   - **Classic 2.91 Original**: สกิน Nullsoft Winamp 2.91 ดั้งเดิม ใช้ภาพสไปรต์แท้ทั้งหมด (Dark Titanium, Black LCD, Green Numbers, Gold Buttons)
   - **Modern Silver Blue**: สกินทรงโมเดิร์นเมทัลลิกสีเงิน-น้ำเงิน ไฟ LED สีฟ้าน้ำทะเล
   - สลับสกินได้สะดวกผ่านปุ่มด้านบน หรือคลิกขวาที่หน้าต่าง / คลิกไอคอน Winamp ที่มุมซ้ายบนเพื่อเปิด Winamp Main Menu

7. **คีย์ลัดคีย์บอร์ด (Keyboard Shortcuts)**
   - `Z`: เพลงก่อนหน้า (Previous)
   - `X`: เล่นเพลง (Play)
   - `C`: หยุดชั่วคราว / เล่นต่อ (Pause/Resume)
   - `V`: หยุดเพลง (Stop)
   - `B`: เพลงถัดไป (Next)
   - `L`: เปิดเลือกไฟล์ (Open / Eject)
   - `S`: เปิด/ปิด Shuffle
   - `R`: สลับโหมด Repeat
   - `Space`: เล่น / หยุดชั่วคราว
   - `↑` / `↓`: เพิ่ม / ลดเสียง 5%
   - `←` / `→`: ถอยหลัง / ก้าวหน้า 5 วินาที
   - `Delete`: ลบเพลงที่เลือกออกจากเพลย์ลิสต์
